1这个工具是干嘛的

想象这个场景：老板给你一张 Excel，里面有 200 行数据 —— 每行是一个门店名 + 一个链接。要你为每一行做一张二维码图片，图片文件还得按门店名命名，方便发给各个店长。

一个个去在线网站生成、下载、改名，200 张能让你干一下午，而且数据还得上传到别人服务器。

这个工具解决的问题就是：你把这张表格丢进去，它一次性生成 200 张二维码（带颜色、带 LOGO、带门店名文字），自动按门店名命名，打包成一个 ZIP 给你下载。整个过程几秒钟，而且数据从头到尾没离开你的电脑。

核心能力一句话总结：
  • 数据进，二维码出 —— 表格里多少行，就生成多少张，一一对应
  • 支持 两列：第一列是「图片名称」（也是文件名 + 可作显示文字），第二列是「二维码内容」
  • 数据来源：手动粘贴 / 导入 Excel·CSV·文本
  • 样式可调：尺寸、静区、前景背景色、四档容错率、圆点/圆角/方形
  • 可加 LOGO（≤25%）与 上/下展示文字
  • 导出 PNG / JPG / SVG，还能一键打包成 ZIP
  • 所有处理都在你自己的电脑浏览器里完成，绝对不上传

它不做什么（避免误解）

  • ❌ 不提供在线服务 —— 它是一个本地 HTML 文件，双击打开就能用，断网也行
  • ❌ 不帮你改二维码内容 —— 二维码内容一旦生成就固定了，不可修改，要改就重新生成
  • ❌ 不做 A4 排版打印 —— 那是另一个独立工具的事，本项目专注「数据 → 二维码」

和「A4 排版工具」的区别

工具输入输出
本工具（批量生成）一行行数据（门店名、链接…）一张张二维码图片 + ZIP
A4 排版工具一堆现成的二维码图片每张铺满一整页 A4 的图片 + ZIP

两个可以配合用：先用本工具生成二维码图片，再用 A4 工具排版打印。

双击 app.html，用 Chrome 或 Edge 打开（推荐 Chrome）。无需安装、无需服务器。

2

填数据（或导入）

在左侧「二维码数据」框里按 名称, 内容 一行一条粘贴；或点 导入 Excel / CSV。第一次用建议先点 下载模板 拿一份规范 CSV。

右边「样式与尺寸」里可以改尺寸、颜色、容错率；需要的话展开「LOGO 设置」「展示文字」加上去。不改也能直接用。

只要单个？ 用预览区的 ← 上一张 / 下一张 → 翻到想要的那张，点 下载当前这张 即可。

3界面导览：屏幕上有哪些东西

打开后界面分左右两栏。左栏是「数据 + 设置」，右栏是「预览 + 文件清单」。

左栏：四个步骤卡片

卡片做什么
1 二维码数据填写/导入两列数据；下方有一排整理按钮（替换、去首尾空格、去除重复行、删除空行）

4 导出选输出格式（PNG/JPG/SVG），然后导出单张或批量打包

右栏：预览与清单

  • 预览：显示当前这一条的二维码效果，标题右侧会显示「版本 N · 模块尺寸 · 容错等级」
  • 文件清单：列出所有将要导出的文件及文件名，点任意一行可跳到该条预览
  • 数据很多时清单只显示前 500 条（不影响导出，导出的还是全部）
改完数据或样式，预览区会自动刷新；右侧预览是按你的屏幕像素比高倍率渲染再缩小的，所以放大看也很清晰，不会糊。

4准备数据：两列怎么写

数据框里一行就是一条二维码，一行里可以写两列：

图片名称, 二维码内容
门店A-桌贴, https://example.com/a
门店B-海报, https://example.com/b
物料M001, 商品编号 A-001

两列分别是啥

列作用可否省略
第一列 图片名称① 用作导出的文件名；② 若开启「展示文字」并选「用图片名称」，会印在二维码下方可以省略（见下）
第二列 二维码内容扫码后真正显示的内容（网址、编号、一段文字…）不建议省略

分隔符用哪个？

  • 英文逗号 , —— 手动输入时最方便
  • Tab（制表符） —— 从 Excel 里直接复制粘贴过来就是 Tab 分隔，不用管

只写一列行不行？

行。只写一列时，这一列会被当成「二维码内容」，名称留空，导出时按「图片名称」卡片里的规则自动编号。

https://example.com/只有内容也行
https://example.com/第二条
内容里有逗号 / 引号 / 换行怎么办？ 用英文双引号把整段包起来即可，例如 "洛漫,西餐厅" 或 "第一行\n第二行"。工具会自动识别引号，把里面的逗号当作内容而不是分隔符。
中文完全没问题。 内容支持 UTF-8，中文、emoji、特殊符号都能生成。

2

双击用 Excel 或 WPS 打开，第一行是表头（名称、内容），下面一行行填。

6数据整理：替换、去重、去空格

数据框下方有一排小按钮，改完会立刻写回数据框（所见即所得）：

按钮作用什么时候用
替换把左框「查找」里的文字，全部替换成右框「替换为」的内容批量换域名、换前缀
去首尾空格删掉每条名称和内容两边的多余空格从别处复制来、带了空格导致扫不出时
去除重复行内容相同的行只保留一条复制粘贴时不小心重复粘贴
删除空行把没有内容的空行删掉表格末尾有多余空行
数据框上方还有一行实时统计：总条数、唯一内容条数，并会标出「内容重复X条」「超长X条」「缺内容X条」。导出前扫一眼这行，能提前发现很多问题。
「超长」是什么？ 二维码能装的内容有上限。内容太长会超出二维码容量、无法生成。看到「超长」提示，就该把内容精简（例如用短链接）。

7调样式：尺寸、颜色、圆点

「样式与尺寸」卡片里能调这些：

选项说明建议
尺寸（px）输出图片的边长，单位像素屏幕展示 300–600；要印刷就调大，比如 1000+
静区边距（模块数）二维码四周的留白宽度。这是扫描器识别所必需的保持默认 4，不要调到 0
前景色 / 背景色二维码的「点」和「底」的颜色深色点 + 浅色底，对比越强越易扫
容错率L / M / Q / H 四档，见 第 11 节没 LOGO 用 M；有 LOGO 用 H
圆点样式方形（标准）/ 圆点 / 圆角想要好看选圆点/圆角；担心扫不出就用方形
关于颜色的一条铁律： 二维码靠明暗对比工作。一定要「深色码点 + 浅色底」。如果做成浅色点 + 深色底（反色），很多扫描器会扫不出来。彩色可以用，但别太浅、别和底色太接近。
静区别归零。 静区就是二维码外面那圈留白，扫描器靠它判断二维码边界。留白被裁掉或压掉，二维码大概率扫不出。

8加 LOGO 与展示文字

这两个区块默认折叠（点标题就能展开），不用的话不用管它。

LOGO 设置

1

点「选择 LOGO」上传图片

建议用方形、透明或纯色底的 LOGO（PNG 最合适）。上传后左边会显示预览。

2

调「LOGO 占比」

滑块范围 10% – 25%。LOGO 越大越显眼，但越容易挡住二维码导致扫不出，上限锁死在 25%。默认 22%。

3

勾选「LOGO 周围加白色留白」

默认已勾选。LOGO 和二维码点之间留一圈白，能显著提升识别率，建议保持勾选。

加了 LOGO，请务必把容错率设为 H。 LOGO 会遮住二维码中间一块，容错率 H 允许约 30% 的遮挡，才能保证还能扫出来。这是本工具里最容易出错的一步。

展示文字

可以让二维码上方或下方印一行文字（比如门店名），方便人工辨认。

设置说明
位置不显示 / 上方 / 下方（默认「不显示」）
字号（px）文字大小，默认 20
文字来源用图片名称（默认，取第一列）/ 用二维码内容（取第二列）/ 固定文案（所有码印同一句话）
注意： 展示文字只对 PNG / JPG 生效。选 SVG 格式导出时不带 LOGO 和文字（SVG 是纯矢量二维码，方便后期自己排版）。

9选输出格式与命名规则

输出格式

格式特点适合
PNG（默认）线条锐利、支持透明背景，支持 LOGO 与展示文字绝大多数场景，首选
JPG文件小，但不支持透明，边缘可能有轻微噪点需要压体积、且不需要透明时
SVG矢量，可无限放大不糊，适合印刷；不含 LOGO 与文字要交给设计师印刷、后期自己加元素

命名规则（「图片名称」卡片）

决定「名称列为空的行」怎么起名：

  • 用数字排序（默认）—— 按 1、2、3… 顺序编号
  • 用二维码内容 —— 拿内容当文件名
  • 自定义 —— 自己设定前缀/规则
优先级：名称列 > 这里的设置。 只要某行填了名称，就一定用名称；只有名称为空的行才走上面的规则。文件名里的非法字符（\ / : * ? " < > |）会被自动清洗掉。

11怎样扫得出来：容错率与实测

「容错率」是二维码最重要的一个概念，选对它能省掉 90% 的「扫不出来」问题。

等级能容忍多少遮挡/污损容量什么时候用
L 低~7%最大内容特别长、又只在屏幕上扫
M 中（默认）~15%中一般用途，没加 LOGO
Q 较高~25%较小会打印、可能有点磨损
H 最高~30%最小加了 LOGO 就必须用它
一句话记法： 容错率越高，二维码「越结实」（越耐脏、耐遮挡），但能装的内容越少、图案越密。加 LOGO → H，不加 → M，基本够用。

影响能不能扫出来的 4 件事（按重要性）

  1. 静区留白 没被裁掉（至少四周各留 4 个模块）
  2. 对比度 够强（深点浅底，别做反色）
  3. 容错率 与遮挡量匹配（有 LOGO 用 H）
  4. 尺寸 打印出来别太小（建议成品 ≥ 2×2 厘米）

本工具的实测结论

  • 先用 ZXing 解码器（主流扫码 App 同款算法）实测：覆盖版本 1–34、L/M/Q/H 四档、中英混排，全部可正常扫出。
  • 含展示文字的 SVG 还原成图片后，依然能正常解码。
  • 工具每次打开时会自动做一次内核自检，控制台会打印 [自检] QR 内核正常，说明生成引擎工作正常。

12常见问题与排错

Q1：打开是空白 / 按钮点了没反应？

确认用 Chrome 或 Edge 打开，并且是新版（建议 103 以上）。不要用 IE，也不要用手机自带浏览器。若还是不行，参考 浏览器支持。

Q2：生成的二维码扫不出来？

按顺序检查：① 静区边距是不是被调成 0 了（改回 4）；② 是不是加了 LOGO 却没把容错率设为 H；③ 前景/背景色对比是不是太弱；④ 是不是做了反色（浅点深底）。

Q3：提示某些行「超长」？

二维码容量有上限，内容太长就没法生成。缩短内容，或用短链接服务把长网址转短。

Q4：导入 Excel 后中文乱码 / 导入没反应？

优先用 CSV 模板。若是 xlsx 仍异常，另存为 CSV 再导入。确认文件扩展名是 .xlsx / .xls / .csv / .txt 之一。

Q5：文件名里出现了奇怪的字符？

Windows 文件名不允许 \ / : * ? " < > | 这些字符，工具会自动替换成安全字符，属正常现象。

Q6：导出的 ZIP 打不开 / 解压失败？

确认下载完整（文件大小不是 0）。老版本浏览器下 ZIP 会用「不压缩」模式生成，文件会偏大但一定能解压。若解压软件报错，换 Windows 自带解压或 7-Zip 试试。

Q7：数据会上传到网上吗？

不会。 整个工具就是一个本地 HTML 文件，代码在你自己浏览器里跑，没有任何网络请求。可以拔网线验证：断网后功能一切照旧。

Q8：想换一台电脑用怎么办？

直接把 app.html 这一个文件复制过去即可，无需安装任何软件。这就是「单文件工具」的好处。

Q9：一次能生成多少张？

几百到几千张都没有问题。数据量很大时，预览区的文件清单只显示前 500 条（避免卡顿），但导出的是全部。

13术语小词典

词什么意思
二维码一种方形黑白图案，手机一扫就能读到里面的内容（网址、文字等）。
模块 (module)二维码里最小的一个黑/白小方格，相当于二维码的「像素」。
静区二维码四周的留白。扫描器靠它识别二维码的边界，必须有，不能裁掉。
容错率二维码被遮挡/污损后仍能读出的能力，分 L / M / Q / H 四档，越高越结实但容量越小。
LOGO 占比中间放的 LOGO 图片占二维码边长的比例。本工具限制在 10%–25%。
展示文字印在二维码上/下的一行说明文字，方便人工辨认。
CSV逗号分隔的文本表格，任何表格软件都能打开，通用性最好。
xlsxExcel 的表格文件格式。本工具可读取，不依赖任何第三方库。
PNG / JPG / SVG三种图片格式：PNG 清晰可透明；JPG 体积小不透明；SVG 是矢量图、可无限放大。
ZIP压缩包格式，把很多文件打包成一个。Windows 右键「解压缩」即可打开。
预览导出之前，先在屏幕上看看效果对不对。
