1它是怎么工作的

2能做什么

  • 两列数据 —— 第一列「图片名称」（也是文件名与可选显示文字），第二列「二维码内容」；名称为空时自动编号
  • 多种导入 —— 手动粘贴，或导入 .xlsx / .csv / .txt；提供规范 CSV 模板一键下载
  • 数据整理 —— 查找替换、去首尾空格、去除重复行、删除空行；实时统计重复 / 超长 / 缺内容
  • 样式可调 —— 尺寸、静区边距、前景/背景色、四档容错率（L/M/Q/H）、方形 / 圆点 / 圆角样式
  • LOGO 支持 —— 上传 LOGO，占比 10%–25%，可选白色留白衬底
  • 展示文字 —— 二维码上方或下方印文字，来源可选名称 / 内容 / 固定文案
  • 多格式导出 —— PNG（可透明）/ JPG / SVG（纯矢量）
  • 批量打包 —— 一键导出为 ZIP；自研 PKZIP 实现，零第三方库

3三种使用方式

①在线直接用

点上面的「打开批量生成工具」，浏览器里立刻可用。数据只在你本机处理，不会上传。

②下载后双击

下载 app.html 到本地，双击用 Chrome / Edge 打开即可，断网也能用。

③嵌入自己的网页

把 app.html 放到任意静态目录即可，它不依赖任何外部资源（无 CDN、无接口）。也可以直接用 iframe 嵌入：

<iframe src="app.html" width="100%" height="800"></iframe>

隐私保证： 整个工具就是一个 HTML 文件，所有处理都在你的浏览器里完成，不存在任何网络请求，数据不离开你的电脑。可以拔掉网线验证。
浏览器要求： Chrome / Edge 103+、Safari 16.4+、Firefox 113+。老版本浏览器下 ZIP 会回退为不压缩模式（仍可解压），xlsx 导入不可用。
